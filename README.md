# Paula Ng — Portfolio

React + Vite.

```
npm install
npm run dev      # local preview at http://localhost:5173
npm run build    # production files go to dist/
```

## Where things are

- `index.html` — page shell (fonts, title)
- `src/data.js` — **all the text**: jobs, projects, leadership roles, awards, contact info
- `src/components/*.jsx` — one component per section
- `src/styles/*.css` — one stylesheet per section; colors are set at the top of `base.css`
- `public/` — put `photo.jpg` (hero) and `photo-2.jpg` (About box) here
